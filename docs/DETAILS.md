## 3. Retrieval systems

- Text templates: `T` = title; `TS` = title+subjects; `TA` = title+abstract; `TSA` = title+subjects+abstract; `full` = title+authors+subjects+abstract; main template `full`, metadata languages `all`.
- BM25: k1 = 0.9, b = 0.4, stemming = True, stop-word removal = True. Arabic: diacritics and tatweel removed, letter variants unified, light10 stemming; English: Porter stemming (`librag/text.py`).
- Dense: exact cosine search over normalised embeddings; sequence cap 512 tokens; models and prefixes in `config.yaml` (retrieval.dense_models).
- Hybrid: reciprocal rank fusion, k = 60, fusion depth 100.
- Run depth 100. Field ablation: T, TS, TA, TSA, full for bm25, bge_m3; language ablation: en, ar.
